# Estudo de Shaders Customizados em HLSL (Unity)
Projeto de desenvolvimento focado em computação gráfica e estilização visual dentro da engine Unity. O objetivo principal foi aprofundar o conhecimento em HLSL (High-Level Shading Language) — a linguagem utilizada para programar como a luz, as cores e os materiais reagem em uma cena 3D.
Através da escrita manual de códigos, explorei o funcionamento fundamental de shaders (regras de renderização visual) ao recriar efeitos simples do zero. Esse estudo prático foi essencial para compreender a lógica por trás da programação gráfica e como a engine processa materiais na tela, aprimorando minha base técnica no desenvolvimento de jogos.

Hiper-Link do projeto: (https://github.com/RLH107/HLSL-Unity6)
